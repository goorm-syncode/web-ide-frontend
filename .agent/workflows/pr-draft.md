# PR Draft 생성

현재 작업 내용을 기반으로 PR 본문 초안을 작성해주세요.

## 사전 확인

1. 현재 브랜치가 `main` 또는 `develop`인지 확인합니다.
2. 해당 브랜치라면 PR 생성을 중단하고 경고를 출력합니다.
3. 그 외 브랜치라면 정상적으로 진행합니다.

## 중단 조건

아래 경우에는 PR 본문을 작성하지 말고 이유를 먼저 설명합니다.

- 현재 브랜치가 `main` 또는 `develop`인 경우
- 변경사항이 거의 없거나 PR로 올릴 내용이 없는 경우

## 입력 정보

- 현재 브랜치: 자동 확인
- 대상 브랜치: `develop`
- 작업 내용 요약: 사용자가 추가한 내용이 있으면 반영

## 요구사항

반드시 저장소의 PR 템플릿 형식을 따르세요.

다음 섹션만 작성해주세요:

- 작업 내용
- 변경 파일
- 테스트 방법
- 스크린샷 필요 여부

## 작성 규칙

- 현재 브랜치 기준의 핵심 변경사항만 요약합니다
- 변경 파일은 중요한 파일만 간단히 나열합니다
- 테스트 방법은 실제 확인 가능한 형태로 작성합니다
- UI 변경이 있으면 스크린샷 필요 여부를 표시합니다
- 체크리스트는 절대 체크하지 않습니다

## 금지 사항

- file://, cci://, 로컬 경로, 내부 링크 사용 금지
- 이전 작업 내용이나 관련 없는 변경사항 포함 금지
- 포맷 변경만 있는 경우 이를 주요 변경으로 작성하지 않기
- 불필요하게 길게 작성하지 않기

## 출력 방식

조건을 만족하는 경우에만 PR 본문을 작성합니다.

조건을 만족하지 않는 경우:

- 실행 불가 이유
- 필요한 조치
