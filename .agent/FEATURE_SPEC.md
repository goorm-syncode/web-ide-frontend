# Feature Spec

이 문서는 현재 단계에서 구현할 기능의 상세 동작을 정의한다.  
현재 범위는 인증(Auth)과 공통 UI 상태에 한정한다.

모든 구현은 MVP_SCOPE.md, UI_RULES.md, instructions.md를 따른다.

---

## 1. Auth (인증)

### 1.1 회원가입

#### 입력 필드

- 이메일
- 닉네임
- 비밀번호

---

#### 입력값 규칙

##### 이메일

- 필수 입력
- 이메일 형식이어야 한다 (`@` 포함)
- 공백 입력 불가
- 최소 5자
- 최대 50자
- 서비스 전체에서 유니크해야 한다

##### 닉네임

- 필수 입력
- 2자 이상 12자 이하
- 한글 / 영문 / 숫자만 허용
- 공백 입력 불가
- 서비스 전체에서 유니크해야 한다

##### 비밀번호

- 필수 입력
- 최소 8자 이상
- 최대 20자 이하
- 영문 1자 이상 포함
- 숫자 1자 이상 포함
- 특수문자 1자 이상 포함
- 공백 입력 불가

---

#### 유효성 검사 시점

- 입력값 변경 시 1차 검사 수행
- 입력 필드 blur 시 에러 메시지 표시 가능
- 제출 시 최종 유효성 검사 수행

---

#### 필드별 에러 메시지 예시

##### 이메일

- 이메일을 입력해주세요.
- 올바른 이메일 형식을 입력해주세요.
- 이메일은 5자 이상 50자 이하로 입력해주세요.
- 이미 사용 중인 이메일입니다.

##### 닉네임

- 닉네임을 입력해주세요.
- 닉네임은 2자 이상 12자 이하로 입력해주세요.
- 닉네임은 한글, 영문, 숫자만 사용할 수 있습니다.
- 이미 사용 중인 닉네임입니다.

##### 비밀번호

- 비밀번호를 입력해주세요.
- 비밀번호는 8자 이상 20자 이하로 입력해주세요.
- 비밀번호는 영문, 숫자, 특수문자를 모두 포함해야 합니다.

---

#### UI 동작

- 모든 입력값이 유효성 검사를 통과했을 때만 회원가입 버튼 활성화
- 유효성 검사 실패 시 Input 하단에 에러 메시지 표시
- 서버 중복 검사 실패 시 필드 또는 MessageBox로 표시
- 제출 중 버튼 비활성화
- 중복 제출 방지

---

#### 제출 동작

성공:

- 로그인 페이지로 이동
- (선택) 성공 메시지 표시

실패:

- 입력값 오류 → 필드 메시지 우선 표시
- 서버 오류 → MessageBox 표시

---

#### 예외 처리

- 네트워크 오류:
  - "네트워크 오류가 발생했습니다. 잠시 후 다시 시도해주세요."
- 서버 오류:
  - "회원가입 처리 중 문제가 발생했습니다."
- 중복 이메일/닉네임:
  - 서버 응답 기준으로 처리

---

#### 화면 구성

- 중앙 Card 레이아웃
- 입력 필드 3개
- 회원가입 버튼
- 로그인 이동 링크

---

## 2. 공통 UI 상태

---

### Loading

- 요청 처리 중 버튼 비활성화
- 로딩 상태 표시 가능
- 레이아웃 변동 없음

---

### Error

- MessageBox 컴포넌트 사용
- 사용자 친화적 메시지 사용
- 내부 에러 정보 노출 금지

---

### Disabled

- 버튼 비활성화
- hover 효과 없음
- 클릭 불가

---

## 3. 공통 UX 규칙

- 입력값 validation은 프론트에서 1차 수행
- 서버 응답을 최종 기준으로 반영
- 서버 에러는 MessageBox로 표시
- Enter 입력 시 제출 가능 여부는 버튼 상태와 동일하게 처리
- 제출 중 중복 요청 방지
