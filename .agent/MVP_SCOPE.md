# MVP Scope

이 문서는 프로젝트의 최소 기능 범위를 정의합니다.  
현재 단계에서는 인증(Auth)과 공통 UI 기반 구현만 포함한다.

모든 구현은 이 범위를 기준으로 진행한다.

---

## Must (필수 기능)

### 인증 (Auth)

- 로그인
- 회원가입
- 비밀번호 재설정
- 로그아웃
- 기본적인 입력값 유효성 검사

---

### 인증 규칙

- 로그인은 이메일과 비밀번호를 사용한다
- 이메일은 사용자 고유 식별자(ID)로 사용한다
- 이메일은 중복될 수 없다
- 닉네임은 중복될 수 없다

---

### 회원가입 입력값

- 이메일
- 닉네임
- 비밀번호

---

### 공통 UI 컴포넌트

- Button
- Input
- Card
- MessageBox

---

### 공통 레이아웃

- 인증 화면용 중앙 카드 레이아웃

---

## Should (있으면 좋은 기능)

- (현재 없음)

---

## Could (여유 시)

- 간단한 사용자 정보 표시 (닉네임)

---

## Out of Scope (이번 단계 제외)

다음 기능은 현재 단계에서 구현하지 않는다:

- 워크스페이스 관련 기능
- 파일 관리 (File Tree)
- 에디터 (Monaco Editor 포함)
- 채팅 기능
- 실시간 기능 (웹소켓 포함)
- 협업 기능 (락, 공동 편집)
- 문제 풀이 / 실행 기능
- 다크 모드
- 상태바 UI
- 관리자 기능
