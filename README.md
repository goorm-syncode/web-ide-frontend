# Web IDE Frontend

웹 IDE 팀프로젝트 프론트엔드 저장소입니다.  
Vite + React + JavaScript + CSS 기반으로 구성되어 있습니다.

## 기술 스택

- Vite
- React
- JavaScript
- React Router
- Redux Toolkit
- Axios
- Monaco Editor
- CSS
- ESLint
- Prettier

## 실행 환경

- Node.js 24 LTS 권장
- npm 사용

## 시작 방법

```bash
npm install
npm run dev
```
